Get 10 billion AI tokens a month, free

Here's everything from the reel. The tool is FreeLLMAPI, an open-source router made by @tashfeenahmed and 149 contributors. Lots of AI companies give you a free tier, but each one is small on its own. FreeLLMAPI stacks them all behind one address, so any app that talks to OpenAI can use the whole free pool. What I like: you stop juggling a dozen keys and a dozen limits.

What you need

  • A computer. Windows, Mac (macOS 12 or later) or Linux. No graphics card needed, the AI runs on the providers' servers.
  • Free accounts with a few AI providers (Google AI Studio for Gemini, Groq, Mistral, NVIDIA and so on). Each one gives you a free API key. You only need one to start, and every extra one adds to your pool.
  • For the server version only: Docker. The desktop app doesn't need it.
  • Cost: nothing. There's an optional $19/yr plan that gets brand-new models the same day instead of 30 days later. You don't need it.

Install it

  1. Get FreeLLMAPI from the Microsoft Store (link on the GitHub page). It's signed, so Smart App Control lets it run, and it updates itself.
  2. Prefer the .exe from GitHub Releases? It's the same app but unsigned. If a blue SmartScreen box shows up, click More info → Run anyway.
  3. Open it from the tray icon. There's no password to set up.
  1. Open the Releases page on GitHub and download the .dmg: arm64 for Apple Silicon (M1 and newer), x64 for Intel Macs.
  2. Open it, drag FreeLLMAPI into Applications, and launch it. It lives in your menu bar.
  1. Install Docker, then run the one-liner below. It sets up ~/freellmapi, makes an encryption key and starts the container.
  2. Open http://localhost:3001 and create your dashboard login.

Use it

  1. Open the dashboard and go to the Keys page. Paste in the free keys from your provider accounts.
  2. On the Models page, pick a routing strategy, or drag the Fallback Chain into the order you like.
  3. Copy your one unified key (it starts with freellmapi-) from the Keys page header or the tray popover.
  4. Point any OpenAI-compatible app at the router's /v1 address (for the server: http://localhost:3001/v1) with that key. Done. If a model hits its limit, the router moves to the next one by itself.

Server one-liner (macOS, Linux, WSL)

curl -fsSL https://freellmapi.co/install.sh | bash

Needs Docker. Want to read it first? Open https://freellmapi.co/install.sh in your browser.

Hook up Claude Code

npx freellmapi setup-claude --url http://localhost:3001 --api-key <your-unified-key>

It backs up your existing config first. Add --dry-run to preview. There are setup commands for Codex, Cursor and more on the GitHub page.

What you get

One endpoint

Chat, embeddings, images, speech and transcription through the same /v1 address.

Auto failover

Rate limits, timeouts and dead keys skip to the next model, up to 20 tries.

Your agents

Claude Code, Codex CLI, Gemini CLI, Cursor, Cline, Aider and more.

Encrypted keys

Your provider keys are AES-256-GCM encrypted on your own machine.

Good to know

  • It's made for personal projects and experiments, not production. Swap in a paid API before you ship something real.
  • No frontier models, speed varies, and the strongest models hit their daily caps late in the day (they reset at UTC midnight).
  • You still agree to each provider's terms when you make the account, and they still apply through the router.
  • Free installs get new models 30 days after they land; that's the only thing the paid plan speeds up.
