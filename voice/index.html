Free AI voices, music and transcripts on your own computer

Here's everything from the reel. The app is audio.cpp, a free, open-source engine made by 0xShug0 (ShugoAI) and a crowd of contributors. It runs 154 families of audio AI models from one place: text to speech, voice cloning, music, sound effects and speech to text. It comes with a click-around web studio, and nothing gets uploaded. I made the voice and the music in the reel with it.

What you need

  • A computer with Windows (x64), macOS (Apple Silicon or Intel) or Ubuntu Linux.
  • A graphics card helps but isn't a must. There are builds for NVIDIA (CUDA), AMD and others (Vulkan), Apple (Metal) and plain CPU. Small voices like Kokoro and PocketTTS run fine on CPU; music and the big voice models want a GPU.
  • Disk space for the models you pick. You download only the ones you want, from inside the app.

Install it

  1. Open the Releases page on GitHub and download the Windows x64 package for your hardware: CUDA for NVIDIA cards, Vulkan for most other GPUs, CPU if you have no graphics card.
  2. For CUDA: also download the separate cudart archive and extract it into the same folder as the app files.
  3. Unzip everything into one folder. If Windows shows a blue SmartScreen box when you run it, click More info → Run anyway.
  4. Open a terminal in that folder and start the studio: audiocpp_server --ui --ui-management --backend cuda (swap cuda for vulkan or cpu to match your download).
  1. If you use Homebrew, run the three commands below.
  2. Or download the macOS package (Metal) from the Releases page.
  3. Start the studio with audiocpp_server --ui --ui-management.
  1. Download the Ubuntu x64 package (CPU or Vulkan) from the Releases page and unpack it.
  2. Start the studio with audiocpp_server --ui --ui-management --backend vulkan (or cpu).

Use it

  1. Open http://127.0.0.1:8080 in your browser.
  2. Go to the Models tab and download a model. Kokoro or PocketTTS are quick, light starting points.
  3. Open Studio, pick the model, type your text and press Run.
  4. To clone a voice, pick a model that supports cloning (like Qwen3-TTS Base) and give it a short, clean recording of the voice plus what it says.

From the official README.

What you get

Voices and cloning

Dozens of text-to-speech models, many of them able to clone a voice from a short sample.

Music and sound effects

Models like ACE-Step 1.5 make whole instrumental tracks; others make sound effects.

Speech to text

Transcribe recordings with models like Qwen3-ASR and Nemotron ASR, in many languages.

Fast and private

Selected models run up to 8x faster than their Python versions, and everything stays on your machine.

Good to know

  • Check the licence of each model. audio.cpp itself is Apache-2.0, but every model keeps its original licence and some don't allow commercial use. The repo has a list: docs/model_licenses.md.
  • Speed and quality depend on the model and your hardware. The 8x figure is for selected models against their official Python code.
  • It's a young, fast-moving project, so expect a few rough edges. The GitHub issues page is active.
